# Runbooks

Agent-driven runbooks for taking a vibe-coded application to an IT-supportable, enterprise-ready state. Both are stand-alone: copy either into a target repo and use it as-is.

| Runbook | Use it when |
|---------|-------------|
| [Enterprise Hardening Review](./enterprise-hardening-review-runbook.md) | You have a production app and want a frontier model (master agent plus sub-agents) to audit it against Scalable / Stable / Secure, produce an evidence-backed scorecard, a phased hardening plan, and verification gates. Copy-paste prompts included. |
| [Vibe-to-Enterprise Skills](./vibe-to-enterprise-skills-runbook.md) | You want a reusable skill set (SKILL.md files), Copilot / Claude instruction files, prompt files, and a custom agent so every future app starts from the same supportable baseline. Sample files and generator prompts included. |

Both documents deliberately contain no time estimates. Ordering is by dependency and severity only.
